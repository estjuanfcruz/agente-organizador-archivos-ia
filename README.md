# Agente Inteligente Organizador de Archivos - Fase 2 (Búsqueda en Espacio de Estados)

Este repositorio contiene la implementación y benchmark de algoritmos de búsqueda no informada (BFS, DFS) e informada (A*) aplicados al problema de organización automatizada de directorios y descargas.
